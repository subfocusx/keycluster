# Чек-лист приёмки UX-улучшений (4 лейки)

Дата: 2026-11-05. Проверяется после слияния лейк A–D в `feature/ux-improvements`.
План и обоснование: `Docs/UX-IMPROVEMENTS.md`.

## Лейка A — Drag & drop

- [ ] Фразу можно перетащить из таблицы на группу в дереве: группа подсвечивается, после drop фраза числится в ней (а не скопирована).
- [ ] Число фраз в группе и её счётчик в дереве обновились после drop.
- [ ] Группу можно перетащить на другую группу — она становится дочерней; вложенность в собственного потомка запрещена.
- [ ] Esc прерывает перетаскивание; drop на мимо ничего не меняет.
- [ ] Не сломаны: выбор фраз (Ctrl/Shift), inline-редактирование, клик по слову (минус-фраза), контекстные меню, выделение текста.
- [ ] Undo отменяет перенос (одним шагом).

## Лейка B — Подписи undo/redo

- [ ] В статус-баре наведение на «↩ N» показывает список последних действий («Перенос 6 фраз в “Кластеры”»).
- [ ] Подписи корректны для: добавления фраз, переноса, удаления в корзину, удаления группы, добавления/снятия минус-фразы, применения кластеризации.
- [ ] Undo/redo работают как раньше; лимит истории (50) сохранён.
- [ ] Числительные согласованы («1 фраза», «2 фразы», «5 фраз»).

## Лейка C — Предпросмотр перед применением

- [ ] Дедупликатор: удаление требует подтверждения через предпросмотр (что и сколько будет удалено, примеры), до подтверждения данные не тронуты.
- [ ] Неявные дубли: тот же паттерн.
- [ ] Кнопки «Применить» / «Отмена» работают; отмена ничего не меняет.
- [ ] Минус-фразы: предпросмотр показывает число затронутых фраз и совпадает с фактическим результатом применения.
- [ ] Существующие сценарии дедупликатора/неявных дублей/минус-фраз не сломаны.

## Лейка D — Панель групп

- [ ] Панель «Управление группами» сворачивается в узкую полосу и разворачивается обратно; состояние переживает перезапуск.
- [ ] Переключатель «дерево слева» переносит дерево влево от таблицы; состояние сохраняется.
- [ ] Контекстное меню группы: «Экспорт фраз (CSV)» скачивает CSV с разделителем «;» и заголовком; «TXT» — по фразе на строку; «Копировать» кладёт фразы в буфер.
- [ ] В экспорт попадают фразы группы и её потомков.
- [ ] Поиск по группам, мультигруппы, контекстные меню, сворачивание подгрупп — работают как раньше.

Дополнительно исправлено при приёмке:
- счётчики в предпросмотре теперь со склонками («1 дубль», «17 фраз», «1 группа») вместо «Останется фраз: 17»;
- положение панели групп (свёрнута/слева/ширина) теперь сохраняется в файле проекта (`.kcproj`), а не только в localStorage — `src/core/project-store-sync.ts`, `project-service-state.ts`, `types/store.ts` + регрессионный тест.

Известные ограничения:
- перетаскивание фразы начинается с маркера `drag_indicator` в строке (перетаскивание по самому тексту оставлено для выделения текста) — как в редакторах;
- подсказки Radix-тултипов в headless-браузере иногда не открываются по наведению — открываются по фокусу, поведение корректное.
